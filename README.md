# 🧮 Calculatrice Scientifique V4

Ma première calculatrice en Python, créée dans le cadre de mon apprentissage de l'IA.

## ✨ Fonctionnalités

- ➕ Addition
- ➖ Soustraction
- ✖️ Multiplication
- ➗ Division (avec protection division par zéro)
- 🔢 Puissance (a^b)
- 📊 Modulo (reste de la division)
- √ Racine carrée (avec protection nombres négatifs)
- 📜 Historique des calculs
- 💾 Sauvegarde automatique dans un fichier
- 📂 Rechargement au démarrage
- 🗑️ Effacement de l'historique

## 🚀 Comment lancer

```bash
python calculatrice.py
